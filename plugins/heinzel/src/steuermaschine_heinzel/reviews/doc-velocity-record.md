## Exactly what it changes

in the project's state home). At most one JSON line is appended, under an exclusive lock on that file; a head that
is already recorded is returned unchanged. No service. It changes neither the merge queue nor any eligibility.

## What moved
`velocity_lib/samples.py` is the old module below its imports (25 names VERBATIM, one meant difference: `Api` has no
default runner); its 49 tests moved byte for byte below a fixture (`coord_verbatim.py` checks both). The cache layer
opens files relative to directory descriptors and never follows a symbolic link; it locks the journal with `fcntl`
inside the moved code (the one place of this slice that locks outside the core; replacing it would change reviewed,
hardened code).
